1. Executive Summary

Modern agentic workflows require balancing latency, model context budget, and reasoning depth. Through testing state-of-the-art coding agents (Antigravity, Cursor, Claude Code), two architectural paradigms dominate the landscape:

Hierarchical (Orchestrator-Worker)

A primary planner agent decomposes goals and delegates isolated sub-tasks to ephemeral subagents. Minimizes context contamination and maintains high alignment.

Sequential / Peer Reactive

Agents share a unified context stream, executing inline tool calls iteratively. Maximizes step-by-step transparency with lower initialization latency.
